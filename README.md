# 교육 출결 검토 및 산출물 생성 자동화

교육 운영 담당자의 반복적인 출결 대조와 Excel·PPT 양식 준비를 지원하는 Windows 데스크톱 프로그램입니다. 출석부, Teams 참석 보고서, 선택적인 중간출결 CSV를 연결해 변경 후보와 확인 근거를 제시하고, 담당자가 검토한 뒤 저장하거나 원본에 반영합니다.

마스터 이력서의 **교육 출결 검토 및 산출물 생성 자동화** 프로젝트에 해당합니다. 현업의 업무 문제를 바탕으로 **Codex와 협업해 제작**했습니다. 관련 문서 생성 워크플로는 3회 이상 반복 적용했으며, 이 횟수를 출결 검토 기능의 사용 실적으로 합산하지 않습니다.

## 주요 기능

- 출석부·Teams·중간출결의 날짜와 명단 확인, 이름 기반 연결 및 중복 이름 검사
- 재접속과 겹치는 접속 구간 병합, 실제 점심·휴게시간을 제외한 확인 후보 표시
- 일반 수업과 프로젝트 운영 방식 구분, 중간출결 없는 수업 지원
- 셀별 변경 전후 값과 근거, HTML 검토 보고서와 JSON 변경 내역 제공
- 분석 이후 원본 변경 여부 확인, 충돌 시 중단, 반영 전 백업과 결과 복사본 저장
- 교육 일정·명단에 따른 날짜별 출석부 및 수강생 산출물 제출용 PPT 양식 생성

지각·조퇴·결석을 자동 확정하지 않으며, 운영 담당자의 최종 검토가 필요합니다. 특정 교육 운영 양식의 시트·셀·슬라이드 구조를 기준으로 구현되어 임의의 Excel·PPT 양식을 지원하지 않습니다.

## 실행

Windows와 tkinter가 포함된 Python 3.13을 사용합니다. 실행 코드는 Python 표준 라이브러리만 사용합니다.

```powershell
py -3.13 run_attendance.py
```

출석부 업데이트에는 호환되는 출석부 `.xlsx`와 Teams 참석 보고서 `.csv`를 선택합니다. 중간출결 CSV는 선택 사항입니다. 생성 기능에는 출석부 양식, PPT 양식, 교육 일정 CSV를 화면에서 지정합니다. 상세 절차는 [사용안내](사용안내.md)를 참고하세요.

공개 저장소에는 개인정보가 포함된 업무용 양식·교육 일정·입력 데이터·분석 결과·기존 실행 파일을 포함하지 않습니다. 기본 양식 경로는 비어 있으므로 본인의 호환 양식을 직접 선택해야 합니다. 이 저장소는 공개용 소스 배포본이며 EXE 다운로드는 제공하지 않습니다.

## 검증

외부 업무 자료 없이 실행할 수 있는 접속 구간·휴게시간·중복 이름·프로젝트 확인 구간 테스트:

```powershell
py -3.13 -m unittest attendance_reference.test_analysis -v
```

실제 명단과 개인 Downloads 경로에 의존하던 통합 테스트는 공개본에 포함하지 않았습니다. 위 테스트는 문서 생성 전체와 실제 운영 파일의 통합 동작까지 검증하지 않습니다.

## 코드 구성

| 경로 | 역할 |
| --- | --- |
| `attendance_app/gui.py` | 파일 선택, 변경 검토, 출석부·산출물 생성 화면 |
| `attendance_app/service.py` | 분석·변경 내역·검토 보고서, 복사본 저장과 원본 반영 |
| `attendance_app/workbook.py` | XLSX 읽기, 셀 변경, 서식·수식 보존 및 원자적 저장 |
| `attendance_app/ooxml.py` | Office ZIP 관계 추적과 불필요한 부분 정리 |
| `attendance_app/generator.py` | 일정과 명단에 따른 출석부·PPT 및 ZIP 생성 |
| `attendance_app/settings.py` | 출력 폴더와 사용자 지정 양식 경로 저장 |
| `attendance_reference/analyze_samples.py` | 명단 연결, 접속 구간·휴게시간 분석 |
| `attendance_reference/inspect_samples.py` | CSV 인코딩과 XLSX 구조 읽기 |

기술: Python 3.13, tkinter/ttk, CSV·JSON, XLSX·PPTX의 ZIP/XML(OOXML) 처리. 기존 업무용 배포는 PyInstaller로 패키징했습니다.

`run_attendance.py --self-test`는 업무용 번들 양식이 있는 패키징 환경의 검사이므로 양식이 제외된 공개본에서는 사용하지 않습니다.
